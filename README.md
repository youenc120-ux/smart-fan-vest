# 溫控風扇背心

把市售空調服（12V 電池、四顆風扇）改裝成**依體感溫度自動調速**的風扇背心，用手機**藍牙**控制。

- **體感溫度控制**：DHT11 同時量溫度與濕度，依熱指數調速，悶熱潮濕時自動吹更強
- **上方、下方分區**：兩組風扇各自 PWM 調速；自動模式下方可設定加強，手動模式兩區分開調
- **遲滯控制**：28°C 啟動、降到 26°C 以下才停止，避免風扇在門檻附近反覆開關
- **中暑警示**：體感溫度過高時，蜂鳴器響、狀態燈閃紅、手機跳出警告並震動
- **心率監測**（MAX30102）：手機顯示即時與最高心率；持續 10 秒高於門檻（預設 150 bpm）時蜂鳴器響、狀態燈閃粉紅、手機震動。這是安全警報，蜂鳴器設定關閉時也會響
- **心率連動風扇**：自動模式下心率接近門檻（門檻 − 20）時風速加 20%，心率警報時直接全速（不受安靜、省電的上限限制），設定裡可關閉
- **熱壓力警示**：體感溫度離中暑警示還差 4°C 以內、但心率已高於「門檻 − 15」並持續 30 秒，就提早發出中暑警示（溫度還沒到、身體已經吃力時）
- **心率紀錄圖**：「紀錄」分頁顯示最近 10 分鐘心率曲線與警報門檻，CSV 也有心率欄位
- **省電**：ESP32 以 80MHz 運作；MAX30102 沒貼到皮膚 10 秒後自動調暗；風扇停止且沒連線時溫濕度改成 5 秒讀一次
- **電源監測**（INA219）：電流、電壓、功率、電池電量估算、本次耗電；超過 3A 自動停止風扇，風扇沒接好也會提醒
- **低電量省電**：電量低於 20% 時限制最高風速 70%，延長使用時間
- **設定記憶**：溫度門檻、警示溫度、模式與風速存在 ESP32，重新開機也不會消失
- **實體按鈕＋RGB 狀態燈**：沒帶手機也能切換模式，燈色顯示溫度等級與警示
- **藍牙配對碼**：避免旁人連上你的背心
- **故障安全**：溫濕度感測器失效時以 70% 安全轉速運轉，不會停止散熱
- 手機用瀏覽器直接連線，免安裝 App；開過一次後離線也能使用，連線時螢幕保持亮著
- **中英雙語介面**：依手機語言自動選擇，右上角按鈕可切換（中／EN），會記住你的選擇
- **喝水／休息提醒**：累計體感溫度高於 32°C 的時間，每 20 分鐘提醒喝水、連續 60 分鐘建議休息（累積熱負荷管理）
- **情境模式**：戶外工作、運動、安靜、省電一鍵切換，實體按鈕連按兩下也能換
- **偏好學習**：記錄你在自動模式下改成手動的風速，自動微調溫度門檻（最多 ±3°C），越用越貼近你的體感
- **開機自我檢測**：上方、下方風扇各轉 1.5 秒量電流，指出是哪一區風扇沒接好
- **平滑調速**：風速慢慢變化，風聲不會突然變大
- **剩餘使用時間**：依即時耗電與電池容量估算還能用多久
- **戶外天氣**：查詢所在地的溫度、體感溫度與紫外線（Open-Meteo），提醒今天會多熱
- **紀錄匯出**：連線期間的溫度、風速、耗電匯出成 CSV，可做報告圖表
- **團隊模式**：一台手機同時監看多件背心，依中暑風險與心率排序，每件背心顯示體感溫度、心率、風速、電量（`team.html`）
- **無線更新韌體（OTA）**：不用拆外殼接 USB，用 Wi-Fi 上傳新韌體
- **診斷頁**：韌體版本、原始數值、狀態旗標

## 專案結構

```
firmware/fan_vest/fan_vest.ino   ESP32 韌體主程式（感測、控制、BLE）
firmware/fan_vest/features.ino   情境模式、喝水提醒、偏好學習、開機自我檢測
firmware/fan_vest/heartrate.ino  心率感測（MAX30102）與心率過高警報
firmware/fan_vest/ota.ino        無線更新（Wi-Fi 熱點＋網頁上傳）
docs/                            手機控制頁（GitHub Pages）；team.html 為團隊模式
hardware/circuit.svg             接線圖
```

## 接線

![接線圖](hardware/circuit.svg)

| ESP32 | 接到 |
|---|---|
| GPIO25 | 上方 D4184 PWM |
| GPIO26 | 下方 D4184 PWM |
| GPIO4 | DHT11 DATA（裸元件另接 10kΩ 到 3.3V） |
| GPIO21 / 22 | INA219、MAX30102 的 SDA / SCL（兩個模組並聯在同兩條線） |
| GPIO14 | 蜂鳴器 |
| GPIO32 | WS2812B DIN |
| GPIO33 | 按鈕（另一腳接 GND） |
| 3V3 | DHT11、INA219、MAX30102、蜂鳴器、WS2812B 的 VCC |
| GND | 所有模組 GND、兩個 D4184 的 GND |
| USB | 電池 USB 輸出孔 |

- 電池 DC 12V → 保險絲 → INA219 VIN+ → VIN− → 兩個 D4184 模組 → 上方、下方風扇
- 1N5819 並聯在每組風扇兩端，白環（陰極）接 +12V
- 電池調速固定在**最高段**，轉速由 ESP32 控制
- DHT11 放在背心內側、不會被汗水直接滴到的位置，用透氣布包著，不要用熱縮套管包死
- 所有 GND 必須共地
- MAX30102 要**貼著皮膚**才量得到，例如縫在領口內側貼脖子，或用延長線接到夾耳垂、手指的夾子；動作太大時讀值會跳，數值僅供參考，不是醫療器材
- 部分紫色 MAX30102 模組的 I2C 上拉接在 1.8V，ESP32 會讀不到；遇到時換一片，或改用綠色／黑色的 3.3V 版本
- 沒接 INA219、MAX30102、蜂鳴器或狀態燈也能正常運作

## 燒錄韌體

1. Arduino IDE 安裝 ESP32 開發板（**core 3.x**）
2. 程式庫管理員安裝 `DHT sensor library`、`Adafruit Unified Sensor`、`Adafruit INA219`、`Adafruit NeoPixel`、`SparkFun MAX3010x Pulse and Proximity Sensor Library`
3. 開啟 `firmware/fan_vest/fan_vest.ino`（同資料夾的 features.ino、heartrate.ino、ota.ino 會一起出現在分頁），開發板選 **ESP32 Dev Module**
4. **工具 → Partition Scheme 選「Minimal SPIFFS (1.9MB APP with OTA)」**，否則程式放不下
5. 上傳

程式開頭的常數可以調整：

| 常數 | 說明 |
|---|---|
| `DHT_TYPE` | 改成 `DHT22` 就能換感測器，接線相同 |
| `BLE_PIN` / `BLE_USE_PIN` | 藍牙配對碼（預設 123456）／是否啟用 |
| `DUTY_MIN` | 風扇最低可轉動的轉速，請實測後調整 |
| `OVERCURRENT_MA` / `FAN_MIN_MA` | 過電流門檻／風扇斷線判斷電流 |
| `BATT_EMPTY_MV` / `BATT_FULL_MV` | 電池空電、滿電電壓，用來估算電量 |

溫度門檻、中暑警示溫度、下方加強、蜂鳴器開關則在手機的「設定」裡調整。

> **電量估算**：預設以 3 串鋰電池（10.2–12.6V）換算。如果你的電池輸出是穩壓 12V（滿電和快沒電時電壓都差不多），電量顯示會一直接近 100%，這時請以電池本身的電量燈為準。可以在滿電和快沒電時各看一次手機上的電壓來確認。

## 實體按鈕與狀態燈

| 操作 | 功能 |
|---|---|
| 短按 | 自動 → 手動 30% → 60% → 100% → 關閉 → 自動 |
| 連按兩下 | 切換情境模式：自訂 → 戶外工作 → 運動 → 安靜 → 省電 |
| 長按 1.5 秒 | 靜音中暑與心率警報、確認喝水提醒、解除過電流保護 |
| 開機時按住 | 進入無線更新（OTA）模式 |

| 燈號 | 意思 |
|---|---|
| 藍／黃／橘／紅 | 自動模式，依溫度等級變色 |
| 白 | 手動模式 |
| 紫 | 溫濕度感測器異常 |
| 紅色慢閃 | 中暑警示 |
| 紅色快閃 | 過電流保護，風扇已停止 |
| 粉紅閃爍 | 心率過高 |
| 每 4 秒閃一下黃 | 低電量 |
| 青色閃爍 | 該喝水了 |
| 綠色 | 開機自我檢測中 |
| 紫色呼吸 | 無線更新模式 |

## 手機控制

開啟控制頁：**https://youenc120-ux.github.io/smart-fan-vest/**

1. 打開背心電源與手機藍牙
2. 點「連線裝置」，選擇 **FanVest**
3. 第一次連線會要求輸入配對碼（預設 **123456**）
4. 切換自動／手動，手動模式分別拖曳上方、下方滑桿

| 平台 | 支援 |
|---|---|
| Android Chrome | ✅ |
| 電腦版 Chrome／Edge | ✅ |
| iPhone | 需改用 [Bluefy](https://apps.apple.com/app/bluefy-web-ble-browser/id1492822055) 瀏覽器（Safari 不支援 Web Bluetooth） |

在網址後面加上 `?demo` 可以不接硬體、用模擬資料預覽介面（團隊模式：`team.html?demo`）。

**團隊模式**：打開 https://youenc120-ux.github.io/smart-fan-vest/team.html ，每點一次「新增背心」加入一件，依中暑風險排序顯示，可以把裝置名稱改成穿著者的名字。每件背心的藍牙名稱會帶晶片編號（例如 FanVest-F011），方便分辨。

## 無線更新韌體（OTA）

1. Arduino IDE 選 **草稿碼 → 匯出已編譯的二進位檔**，在草稿碼資料夾的 build 裡找到 `fan_vest.ino.bin`
2. 背心進入更新模式：手機控制頁「診斷」→「進入無線更新模式」，或開機時按住按鈕（狀態燈變紫色呼吸）
3. 手機或電腦連上 Wi-Fi「FanVest-xxxx-OTA」（密碼 `fanvest123`，在 `ota.ino` 修改），打開 http://192.168.4.1
4. 選擇 .bin 檔上傳，完成後背心自動重開機；5 分鐘沒上傳也會自動重開機

建議在 Chrome 選單選「加到主畫面」，之後像 App 一樣開啟。

> 從舊版韌體升級後如果連不上，請到手機的藍牙設定把「FanVest」取消配對，再重新連線。

## BLE 介面

服務 UUID `7a1e0001-5c2b-4f0a-9d3e-6b8f2a4c9e10`，所有數值 little-endian，詳細欄位見 `fan_vest.ino` 開頭註解。

| 特徵值 | UUID 尾碼 | 屬性 | 內容 |
|---|---|---|---|
| STATUS | `…0002…` | 讀取、通知 | 20 bytes：溫度、濕度、體感溫度、上下轉速、模式、手動設定、電壓、電流、電量、狀態旗標、耗電、開機時間 |
| CONTROL | `…0003…` | 寫入 | 3～4 bytes：自動模式、手動上方%、手動下方%、指令（0～4 情境模式、254 自我檢測、253 OTA、252 清除學習）；也會靜音警報、確認喝水提醒、解除過電流保護 |
| CONFIG | `…0004…` | 讀取 | 9 bytes：最低轉速、故障安全轉速、過電流門檻、電池空滿電壓、低電量轉速上限 |
| SETTINGS | `…0005…` | 讀取、寫入 | 18 bytes：T0／T1／T2、下方加強、中暑警示溫度、蜂鳴器、依體感溫度控制、最高轉速、喝水提醒溫度與間隔、偏好學習、心率警報門檻、心率連動風扇 |
| EXTRA | `…0006…` | 讀取、通知 | 19 bytes：提醒旗標（含 0x40 熱壓力、0x80 心率連動加速中）、連續／累積高溫分鐘、情境模式、自我檢測電流、韌體版本、學習偏移與樣本數、心率狀態、心率、本次最高心率 |

狀態旗標：`0x01` 找不到 INA219、`0x02` 過電流保護、`0x04` 風扇電流過低、`0x08` 中暑警示、`0x10` 低電量、`0x20` 警報已靜音、`0x40` 心率過高。
