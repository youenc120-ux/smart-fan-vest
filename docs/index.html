連線到背心

打開背心電源與手機藍牙，再點下面的按鈕，從清單選擇「FanVest」。第一次連線時手機會要求輸入配對碼（預設 123456）。

這個瀏覽器不支援藍牙網頁連線。Android 請用 Chrome 開啟本頁；iPhone 請改用 Bluefy 瀏覽器。

診斷

韌體版本、原始數值、自我檢測、無線更新

手機沒有讀到新版韌體的進階資料，可能是記住了舊的藍牙資料。請到手機的藍牙設定把 FanVest 取消配對，關閉再開啟藍牙，然後重新連線。

進入後背心會關閉藍牙並開啟 Wi-Fi 熱點「FanVest-xxxx-OTA」（密碼 fanvest123），連上後打開 http://192.168.4.1 上傳新韌體。
